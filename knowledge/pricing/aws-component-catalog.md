## Detailed Component Specification Template

When creating a BOM item for an AWS component, use this format:

```markdown
### Component: [Name]

**Specification**:
- Instance Type: [e.g., m6i.xlarge]
- vCPU: [N] cores
- Memory: [N] GiB
- Storage: [Type, Size]
- Network: [Bandwidth]

**Pricing**:
- Unit Price: $X.XX/hour
- Monthly Cost: $XXX.XX (730 hours)
- Annual Cost: $X,XXX.XX

**Sizing Justification**:
- [Explanation of why this size was chosen]

**Source**:
- Pricing URL: [Link to AWS pricing page]
- Calculator URL: https://calculator.aws/
- Verified Date: YYYY-MM-DD

**Quantity**: [N] units

**Total Monthly Cost**: $X,XXX.XX
```

## Sizing Guidelines

### Small Deployment (< 1,000 cards)
- EC2: m6i.large (2 vCPU, 8 GiB)
- RDS: db.m6i.large (2 vCPU, 8 GiB)
- ElastiCache: cache.m6g.large (2 vCPU, 5.3 GiB)
- ALB: 1 unit
- EKS Cluster: 1 unit

### Medium Deployment (1,000 - 10,000 cards)
- EC2: m6i.xlarge (4 vCPU, 16 GiB) × 2
- RDS: db.m6i.xlarge (4 vCPU, 16 GiB) Multi-AZ
- ElastiCache: cache.m6g.xlarge (4 vCPU, 13.5 GiB) × 2
- ALB: 2 units
- EKS Cluster: 1 unit

### Large Deployment (> 10,000 cards)
- EC2: m6i.2xlarge (8 vCPU, 32 GiB) × 4
- RDS: db.r6i.xlarge (4 vCPU, 32 GiB) Multi-AZ
- ElastiCache: cache.r6g.xlarge (4 vCPU, 32.3 GiB) × 3
- ALB: 2 units
- EKS Cluster: 1 unit
