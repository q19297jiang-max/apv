# apv-reviewer Skill

## Overview

Perform unified approval verification for RFP responses, replacing the original 5-gate approval process with a single comprehensive 15-minute review.

## Purpose

- Verify source URL compliance (100% required)
- Check completeness of response
- Verify accuracy against knowledge base
- Approve/Conditional/Reject decision

## Unified Approval Concept

**Original Process**: 5 separate approval gates × 30 minutes = 150 minutes
**New Process**: Single unified 15-minute review (90% time reduction)

## When to Use

- After [[rfp-generator-skill]] has created the RFP response document
- Before submitting the RFP response to the customer
- For final quality assurance and approval

## Inputs

- RFP Response Document: Generated by [[rfp-generator-skill]]
- Original RFP: Customer requirements document
- APV Knowledge Base: For fact verification

## Outputs

1. **Verification Report**: Pass/Fail for each checklist item
2. **Issues Found**: List of any problems requiring correction
3. **Approval Decision**: Approve, Conditional, or Reject
4. **Confidence Score**: Overall confidence in the response
5. **Review Timestamp**: Date/time of review

## Unified Checklist

### Source URL Verification (CRITICAL - 30% weight)
- All compliance claims have source URLs
- All pricing claims have calculator URLs
- All architecture claims cite vendor documentation
- Source URLs are valid (verified)
- Source URLs within freshness threshold
- Evidence artifacts referenced

### Content Verification (25% weight)
- All RFP questions addressed
- Executive summary complete
- Technical solution complete
- Compliance matrix complete
- Implementation plan complete
- Pricing complete with breakdown

### Accuracy Verification (25% weight)
- Facts match APV knowledge base
- No fabricated claims
- No contradictory statements
- Calculations are correct
- Assumptions documented

### Compliance Verification (15% weight)
- PCI-DSS requirements mapped (12/12)
- Country regulations mapped
- Evidence specified
- Certifications listed
- Gaps identified

### Quality Verification (5% weight)
- Document professionally formatted
- Tables and figures clear
- No spelling/grammar errors
- Citations properly formatted
- Appendices complete

## Confidence Score

```
Overall Confidence = (SourceURL% × 0.30) + (Completeness% × 0.25) + (Accuracy% × 0.25) + (Compliance% × 0.15) + (Quality% × 0.05)
```

## Approval Criteria

- ✅ **APPROVE**: Critical items pass, Source URL ≥95%, Confidence ≥90%
- ⚠️ **CONDITIONAL**: Critical items pass, Source URL ≥90%, Confidence ≥80%
- ❌ **REJECT**: Critical fails, Source URL <90%, Confidence <80%

