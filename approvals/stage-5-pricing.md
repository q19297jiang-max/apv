# Stage 5: Pricing Review Checklist (with Source URL Verification)

## Purpose

Validate all pricing calculations with official calculator URLs and evidence screenshots.

## Checklist Items (3 checks + SOURCE URL CHECKS, 3 minutes)

### 5.1 Cost Calculation Accuracy
- [ ] Unit prices verified
- [ ] Quantities match sizing
- [ ] Totals calculated correctly
- [ ] Source URL verification:
  - [ ] All prices cite official calculator URLs
  - [ ] Calculator URLs work and accessible
  - [ ] Calculator screenshots provided
  - [ ] Screenshot location: wiki/apv/knowledge/evidence/pricing/YYYY-MM-DD/

### 5.2 Pricing Freshness
- [ ] Pricing verified within 30 days
- [ ] Calculator date documented
- [ ] Verification documented by Infrastructure Architect

### 5.3 Completeness
- [ ] All components priced
- [ ] Support included (10% typical)
- [ ] Annual projection provided

## Approval Decision

**Status**: [ ] Pass [ ] Needs Re-verification

**Pass Criteria**: All source URLs verified, calculator evidence present

**Specialist Trigger**: Custom pricing or non-standard configuration

**Evidence File**: `wiki/apv/.rfp-session/{BANK_NAME}/approvals/stage-5-pricing.md`
