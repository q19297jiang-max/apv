## Pricing Methodology

```
Source URL: {{METHODOLOGY_REFERENCE}}

Total Monthly Cost =
  Compute Cost +
  Database Cost +
  Storage Cost +
  Network Cost +
  Load Balancer Cost +
  Monitoring Cost +
  Support Cost

Compute Cost = Instance Price × Hours × Instances × (1 + Reserved/Savings Discount)
Database Cost = Database Price × Hours × Instances
Storage Cost = GB Price × Storage GB × (1 + Tiered Discount)
Network Cost = GB Price × Data Transfer GB
```
